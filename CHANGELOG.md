# Changelog

## 0.1.0 — Initial release

- Self-contained extraction of the `/plan-review` command from cc-viz.
- New: ASCII UI mockups inline for every `[UX]`-tagged change.
- New: Plain English translation layer with header toggle (state persists in localStorage).
- New: `UX Flows` aggregate view — every before/after mockup grouped by screen.
- New: `[UX]` tag heuristics applied during the data-gathering phase.
- New: `⚑ missing rationale` flag on changes where the plan says what but not why.
- Bundled references: html-structure, css-patterns, mermaid-theming, ascii-ui-mockups, plain-english.
- Bundled reference template demonstrating Blueprint aesthetic.
